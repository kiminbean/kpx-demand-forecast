# 2차 라운드: 정정된 인과 파이프라인 NWP CV 재산출

> 라운드: 총 3차 중 2차 (2026-11-14)
> 상위 지시: 이전 라운드의 금지·연기 항목 반복 금지, 2차 라운드 문서 작성 후 커밋·푸시.
> 1차 라운드(docs/round1_dayahead_causality.md)가 남긴 후속 과제 수행.

## 배경

1차 라운드에서 day-ahead(NWP) 파이프라인의 두 인과성 위반(마감 이후 종료 구간의 학습
포함, day2→day1 폴백)을 정합화했다. 그 결과 AGENTS.md·문서의 NWP day-ahead
FER 8.53~8.65%(테스트)와 CV 8.5~8.7%는 위반 마스크 + 폴백 하에서 얻은 **역사적
수치**가 됐고, 1차 라운드는 테스트 윈도우 보호 규칙 때문에 정정 수치를 산출하지 않고
CV 재산출만 후속으로 남겼다. 이번 라운드는 그 재산출이 목적이다.

## 변경 사항

- 코드 변경 없음. 허용된 경로(`--cv`, 테스트 미사용)로 재산출만 수행.
  ```
  .venv/bin/python scripts/train_solar_v2.py --variant {island_mean,stations_level} \
      --weather {nwp_msm_day2,nwp_msm_day1} --cv
  ```
- 문서 갱신: AGENTS.md 인과성 주석에 정정 CV 수치 추가,
  docs/solar_evaluation_criteria.md §7 CV 항목에 역사적 수치 주석 + 정정 수치 병기.

## 재산출 결과 (CAPACITY_SELECTION = 384.87 MW, 월별 rolling-origin CV 5~10월 + 검증 [09-13 12:00, 11-07 06:00))

|---|---|---|---|---|---|---|

| day2 | stations_level | **8.501%** | 15.11 | 29.54 | 8.058% | 13.74 |
| day1 (낙관적 참고, 24h 전) | island_mean | 8.028% | 13.66 | 26.16 | 7.218% | 11.41 |

09월 7.49 / 10~11-06 8.09. stations_level: 9.82 / 9.75 / 10.89 / 5.81 / 7.29 / 7.78.

### 역사적 수치와의 비교 (같은 CV·검증 정의)

- island_mean day2: CV 8.686% → 8.752% (+0.07pp), 검증 8.828% → 8.640% (−0.19pp).
  요인: 마감 이후 종료 구간이 학습에서 빠져 학습 집합이 작아졌고(약 1~2일 분량/폴드),
  검증 학습 마스크는 TEST_START 마감 기준이라 검증 구간 학습분이 늘어난 방향으로도 작동.
  변화폭은 폴드 간 변동(±2pp)보다 작다 — **수준·결론은 불변**.
- day1(폴백 아닌 명시적 조건): 역사적 CV 참고값 7.8% 대비 8.03~8.11%로 소폭 상향.
  day1은 D-1 10:00 마감 이후 발표분이 섞일 수 있어 어디까지나 낙관적 상한이다.

## 결론

- **정정된 엄격 마감 조건에서도 day-ahead FER은 CV 8.5~8.8%로 ≤6% 내부 목표를
  못 미친다.** 방향성 결론(목표 미달, 관측기상 4.18%가 상한, 48h 지속성 16.38% 대비
  우위)은 모두 유지된다. 병목은 학습 마스크가 아니라 JMA MSM day2 예보 자체의
  정확도라는 MOS·특허 2단 구조 네거티브 결론과 정합한다.
- 테스트 창(2024-11-07~12-31)의 정정 마스크 재평가는 모델 선택 목적상 금지로 남는다.
  유일한 정상 재평가 경로는 2025 KPX 홀드아웃이다.

  사용자 사전 승인 범위 내.
