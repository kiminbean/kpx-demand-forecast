# 3차 라운드: 2025-01~02 풍력 용량·분모(C) 가정 검증 — 암시 용량 93.2 MW, 판정은 경계 사례 (2026-11-14)

## 요약

2차 라운드 문서(`docs/round2_wind_bias_correction.md`)가 "다음 라운드 제안 1번"으로
사전등록한 **2025-01~02 풍력 용량·분모(C) 가정 검증**을 이번 라운드(3/3차)에서
수행했다. 1~2월 hold-out의 +6.11 MW 과대예측이 분모(등록 용량 104.9 MW) 가정 오류
기인인지, 풍속 정규화 스케일 비교로 정량 확인했다.

**판정(사전등록 기준 기계 적용): r = 0.8885 < 0.90 → 분모 갱신.** 암시 용량
93.2 MW, FER 재산정 15.71%. 다만 **경계 사례**다: 라벨 전환구간(2025-02-25~28,
96 h)을 대상기간에서 빼면 r = 0.9385로 기준을 통과한다(참고용, 판정 미사용).
즉 갱신 판정 자체가 전환구간 포함 여부에 민감하고, "1~2월부터 플릿이 줄었다"는
증거는 약하다 — 라벨 붕괴는 2/25~28에 시작한다.

어느 판정을 따라도 상용 벤치마크 결론은 불변이다: **FER 13.23%(기존 기록)이든
15.71%(갱신 분모)든 단일 소규모 지역 업계 범위 cnMAE 8~13%의 하한권 밖**으로,
풍력 TOP3 판정은 미달 유지. 모델 개선 여지보다 라벨 자체의 문제(2024-06 브레이크
이후 커버리지 18~35% → 2025-03~ 붕괴)가 지배적이라는 것이 3라운드 종합 결론이다.

## 배경

- 1차 라운드: 풍력 2025-01~02 hold-out FER 13.23%, MBE +6.11 MW 과대예측,
  persistence 34.63% 대비 우위. 업계 8~13% 하한권 밖.
- 2차 라운드: 편향 보정 LOFO CV 미채택(2024 OOF MBE +0.08~+0.40 MW, fold별 부호
  요동). +6.11 MW는 2024에서 학습 불가능한 기간 고유 현상으로 판정.
- 2차가 남긴 물음: 분모 가정(92.8~106.7 MW) 자체가 무너졌는가? 2025-03부터 월 최대
  13 MW로 붕괴하는 라벨의 전환 시점과 그 이전 구간의 플릿 규모를 검증.

## 데이터 증거 (라벨 스케일)

`src.features.solar_features_v2.load_kpx_hourly` (K24 지역 '제주' / K25 '제주도'
처리, interval-END 변환) 기준, 월별 라벨 최대(MW):

- 2024-01~05 (브레이크 전): 257 / 255 / 266 / 213 / 282 — 대형 플릿.
- 2024-06~12 (브레이크 후): 70 / 40 / 49 / 64 / 76 / 95 / 102 — 소형 플릿.
- 2025-01 / 02: 96.8 / 101.4 — 2024-12(101.8)와 동일 스케일.
- 2025-03~12: 13.4 / 12.8 / 13.1 / 10.0 / 10.7 / 7.2 / 6.9 / 8.3 / 8.8 / 9.0 — 붕괴.
- 전환은 2025-02-25~28에 계단식 발생: 일 최대 02-24 93.2 → 02-25 19.9 → 02-27 10.4
  → 02-28 3.0 MW. K25 파일의 연료원·지역 스키마는 K24와 동일(파일별 region 지정
  이슈는 2024 파일에만 해당).

즉 2025-01~02는 라벨 단절 이전 구간으로, 분모 가정 검증이 유효한 대상이다.

## 사전등록 절차 (실행 전 고정, scripts/wind_denominator_2025.py docstring)

1. 모델/설정 동결 — 재학습·재선택 없음. 1차 라운드가 저장한
   `models/holdout_2025/wind_holdout_predictions.csv`(phase5_tw0999, interval-END
   라벨)의 실측/예측을 그대로 재사용. hold-out을 모델 선택·튜닝에 쓰지 않는 1회
   재평가 원칙 유지.
2. 스케일 비교: 섬 평균 풍속을 1 m/s 빈으로 나눠 빈별 평균 출력을 비교.
   r = 대상기간(2025-01-01~02-28 END) / 기준기간(2024-08-01~12-31 END, 브레이크 후
   동일 플릿)의 빈별 평균 출력 비율을 기준기간 빈 도수로 가중 평균. n≥20 빈만 사용.
   r < 1이면 대상기간 플릿이 더 작다는 뜻.
3. 방법 검증: 동일 방식을 2024-01~05(브레이크 전 더 큰 플릿)에 적용 — r이 1보다
   충분히 커야 방법이 플릿 규모 변화를 감지한다는 뜻.
4. 판정 기준(실행 전 고정): **r ≥ 0.90 → 분모 가정 유지**(FER 13.23%, C=104.9
   기록 유지) / **r < 0.90 → 분모 갱신**(암시 용량 = r × 104.9 MW, FER을 MAE/암시
   용량으로 재산정).
5. 민감도: 2025-02-25~28 제외 FER/MBE는 참고용으로만 산출, 판정·모델 선택 미사용.
   편향 보정은 재개하지 않음(2차 라운드 미채택 불변).

## 결과

### 스케일 비교 (빈별 정규화, 9 bins)

| 비교 | r | 암시 용량 | 해석 |
|------|-----|-----------|------|
| 2025-01~02 / 2024-08~12 (주 판정) | **0.8885** | **93.2 MW** | 기준 미달 → 갱신 |
| 2024-01~05 / 2024-08~12 (방법 검증) | 2.6872 | 281.9 MW | 브레이크 전 플릿 감지 — 방법 유효 |

방법 검증의 암시 용량 281.9 MW는 2024 상반기 라벨 실측 최대 282 MW와 일치한다.
즉 이 방법은 플릿 규모 변화를 실제 스케일로 정확히 되돌려 놓는다.

### 민감도 (참고용, 판정 미사용)

- 대상기간에서 전환구간 2025-02-25~28(96 h)을 제외하면 **r = 0.9385** (암시 용량
  98.5 MW) — 기준 통과. 분모 갱신 판정은 이 96 h의 붕괴 라벨이 대상기간에
  포함되어 있느냐에 좌우된다.
- hold-out FER/MBE (분모 104.9 MW): 전체 1~2월 FER 13.96%, MBE +6.11 MW /
  전환 전(~02-24) FER 13.65%, MBE +5.17 MW / 전환구간(96 h) FER 18.24%,
  MBE +19.14 MW.
- 전환 전 구간에도 +5.17 MW 과대예측이 남아 있다 — 분모 붕괴만으로 편향이
  설명되지는 않으며, 1차 라운드의 "커버리지가 2024 post-break보다 더 낮아진" 가설
  방향은 유지된다. 편향 보정 미채택 판정은 불변.

### 판정의 성격: 기계 적용은 갱신, 증거는 경계

사전등록 기준을 기계적으로 적용하면 r = 0.8885 < 0.90이므로 분모 갱신이고,
FER는 MAE/93.2 = **15.71%**로 재산정된다(기존 기록 13.23%보다 나쁘다). 그러나
r이 기준을 0.011 낮은 수준이고, 기준을 통과시키는 제외 민감도(0.9385)가 존재하며,
1~2월 라벨 최대(96.8/101.4 MW)는 2024-12(101.8 MW)와 동일 스케일이라는 독립
증거도 있다. **기록상 취지: 갱신 판정을 남기되 "1~2월 플릿 감소"는 확정 증거로
쓰지 않는다.** 어느 쪽이든 아래 TOP3 판정은 바뀌지 않는다.

## 풍력 TOP3 판정 갱신 (상용 벤치마크 비교)

| 벤치마크 | 풍력 수치 | 판정 |
|----------|-----------|------|
| 단일 소규모 지역 상용 cnMAE 8~13% | 13.23% (C=104.9, 1차 기록) ~ 15.71% (C=93.2, 갱신 분모) | **하한권 밖 — 미달 유지** |
| 48h persistence (34.63%) | 13.23~15.71% | 우위 유지 (스킬점수 유의) |
| 분모 가정 강건성 | C 93.2~104.9 MW 범위에서도 미달 | 판정 불변 |

분모를 가장 불리한 쪽(93.2 MW)으로 바꿔도 판정이 뒤집히지 않으므로, 풍력의 미달은
분모 가정 오차로 회복 가능한 수준이 아니다. 라벨이 시장 풍력의 18~35%만 커버하고
2025-03부터 붕괴하는 상태에서는 커버리지 회복(외부 라벨 확보)이 선행 과제이며,
모델 측 개선(편향 보정 등)은 이미 2차에서 기각됐다.

태양광 TOP3 판정(1차 라운드 확정: island_mean 7.32% vs KPX 본토 참여자 평균 5.6%,
stations_level 5.53%는 참여자 평균 내)은 이번 라운드와 무관하게 유지된다.

## 3라운드 사이클 종합

1. 1차: hold-out 사전등록 재평가 + TOP3 판정 — 태양광 7.32/5.53%, 풍력 13.23%,
   양자 모두 상용 기준 미달(태양광 stations_level만 참여자 평균 내).
2. 2차: 풍력 편향 보정 — 미채택 확정.
3. 3차(본 라운드): 풍력 분모 검증 — r = 0.8885(갱신 기준 미달, 경계 사례),
   암시 용량 93.2 MW, 갱신 FER 15.71%. TOP3 미달 판정 강건 확인.

남은 개선 경로는 모두 모델 밖에 있다: (a) 커버리지 회복 — 2025 KPX 지역 라벨
스키마('제주도') 확인 후 2025-03+ 붕괴 원인 규명, (b) 2025 재학습 주기(태양광,
1차 제안 2번 계류), (c) stations_level lvl_p API 근사(1차 제안 3번 계류).
