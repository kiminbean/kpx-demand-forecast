# 해줌 특허(KR101808047B1) 2단 구조 반영 실험 결과

> 특허: 태양 에너지를 이용하는 발전소의 발전량을 예측하는 방법 및 서버 (10-2016-0099850, KR101808047B1)
> 실행: `scripts/patent_two_stage.py`, 산출물: `models/solar_v2_nwp_patent/*.json` (gitignored)
> 날짜: 2026-11-10

## 특허 구조와의 대응

- **NN1 (적정 발전량 함수)**: SolarV2Model(`island_mean`)을 관측 기상(ASOS)으로 학습.
- **NN2 (기상예보 보정 네트워크)**: JMA MSM day2 예보 → 관측(ASOS) 변수·관측소별 선형 보정기
  (`obs = a·fcst + b`)을 발전모델 **앞에** 배치. 특허 원문은 NN2가 NN1의 1층 활성값을 목표로
  학습하지만, 본 스택에서는 선형 보정으로 단순화해 동일한 2단 구조(예보→관측 보정→발전모델)를 구현.
- 거리가중 보간·시간 보간·발전소별 미세조정은 섬 전체 집계 + 단일 데이터셋이라 해당 없음.
- 기존 `mos_correct_nwp.py`(발전모델 뒤 일사 사후 보정, 네거티브)와 구조적으로 상이.

## 실험 프로토콜 (사전 등록)

- 선택은 월별 rolling-origin CV(train_solar_v2.py 동일 CV_FOLDS)와 검증 구간 [VAL_START, TEST_START)로만.
- 보정기는 각 폴드 시작 이전 데이터로만 적합 (누출 없음).
- 테스트 창 2024-11-07~12-31은 선택 완료 후 **1회만** 평가 (규칙 준수).
- 베이스라인: island_mean day-ahead(nwp_msm_day2) CV 8.686% / VAL 8.828% / 테스트 8.53%.

## 결과 (C = 359.4 MW)

| 방법 | CV FER | VAL FER | 테스트 FER |
|------|--------|---------|-----------|
| 베이스라인 (day2 예보 직접 입력) | 8.686% | 8.828% | 8.53% |
| 2단 구조·단변량 선형 보정 | **8.534%** | **7.921%** | 8.572% |
| 2단 구조·다변량 선형 보정 | 8.777% | 8.320% | 미평가 |

- 선택 기준(CV·검증 양쪽)에서는 단변량이 승리 → 사전 등록대로 테스트 1회 평가.
- **테스트: 8.572% vs 베이스라인 8.53% (+0.04pp) — 사실상 동률, 개선 없음.**
- MAE 12.83 MW는 낮지만(베이스라인 대비) FER 헤드라인 지표는 변화 없음.

## 결론

- 예보→관측 선형 보정(특허 2단 구조)은 CV·검증에서는 개선을 보이지만, 실제 제출 조건의
  테스트 창에서는 효과가 없다. LightGBM이 이미 예보 편향을 흡수한다는 MOS 네거티브 결론과
  같은 방향 — **병목은 보정기 구조가 아니라 JMA MSM day2 예보 자체의 정확도**다.
- 관측기상 상한(테스트 4.18%)에 가려면 Multi-model NWP(ECMWF IFS, KMA LDAPS) 도입 등
  예보 소스 개선이 필요 — AGENTS.md Open Follow-ups와 일치.
- 따라서 특허 기법은 **프로덕션 미채택**. 실험 코드·결과는 기록으로 보존.
