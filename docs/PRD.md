# Product Requirements Document (PRD)
## Project: Jeju Renewable Energy Forecast (J-REF)

---

## 1. 개요 (Overview)

| 항목 | 내용 |
|------|------|
| **프로젝트명** | J-REF (Jeju Renewable Energy Forecast) |
| **목표** | 제주도 내 태양광 및 풍력 발전소의 전력 공급량을 딥러닝 모델로 예측하고, 지도 기반 대시보드로 시각화 |
| **핵심 가치** | 기존 서비스(60hz.io) 대비 **예측 정확도 10% 이상 향상** (Target MAPE < 10%) |
| **타겟 사용자** | 전력거래소(KPX) 관계자, 신재생에너지 발전 사업자, 에너지 연구원 |

---

## 2. 문제 정의 (Problem Statement)

### 2.1 현황 분석
- 제주도는 날씨 변동성이 커서 기존의 광역 기상 데이터 기반 예측은 오차가 큼
- 출력 제어(Curtailment) 발생 시점을 예측하지 못하면 경제적 손실 발생
- 기존 서비스는 '현황' 중심이며, '고정밀 예측' 기능은 부족함

### 2.2 기회 영역
- **Micro-climate 모델링**: 제주도 특유의 지형(한라산, 해안, 중산간)에 따른 국지 기상 반영
- **Dual-Stream Architecture**: 태양광/풍력의 물리적 특성 차이를 반영한 전문화된 모델
- **Real-time Dashboard**: 예측값과 실측값의 실시간 비교 시각화

## 3. 주요 기능 (Key Features)

### 3.1 데이터 수집 및 가공 (Data Pipeline)

```
[Raw Data Sources]
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│  기상청 데이터                                           │
│  - ASOS (종관기상관측): 주요 기상대 관측값               │
│  - AWS (방재기상관측): 제주도 내 상세 관측망             │
│  - LDAPS (수치예보모델): 격자형 예보 데이터              │
└─────────────────────────────────────────────────────────┘
       │
       ▼
┌─────────────────────────────────────────────────────────┐
│  전력거래소(KPX) 데이터                                  │
│  - 시간대별 발전량 (태양광/풍력)                         │
│  - 발전소 위치 정보                                      │
│  - 계통 연계 정보                                        │
└─────────────────────────────────────────────────────────┘
       │
       ▼
[Feature Engineering] → [Model Training] → [Prediction]
```

#### 데이터 소스 상세

| 데이터 | 출처 | 주기 | 활용 |
|--------|------|------|------|
| ASOS | 기상청 | 1시간 | 기본 기상 변수 |
| AWS | 기상청 | 10분 | 상세 지역 기상 |
| LDAPS | 기상자료개방포털 | 6시간 | 예보 기반 예측 |
| 발전량 | KPX 전력통계 | 1시간 | 타겟 변수 |

### 3.2 예측 모델링 (AI Core)

#### 3.2.1 Dual-Stream Model Architecture

```
                    ┌──────────────────────┐
                    │   Input Features     │
                    │  (Weather + Time)    │
                    └──────────┬───────────┘
                               │
              ┌────────────────┴────────────────┐
              │                                 │
              ▼                                 ▼
    ┌─────────────────┐               ┌─────────────────┐
    │   Solar-Net     │               │   Wind-Net      │
    │   (LSTM/GRU)    │               │   (Transformer) │
    │                 │               │                 │
    │ Features:       │               │ Features:       │
    │ - 일사량        │               │ - 풍속          │
    │ - 운량          │               │ - 풍향          │
    │ - 기온          │               │ - 기압          │
    │ - 습도          │               │ - 난류강도      │
    └────────┬────────┘               └────────┬────────┘
             │                                  │
             └────────────┬─────────────────────┘
                          │
                          ▼
               ┌─────────────────────┐
               │  Ensemble Layer     │
               │  (Weighted Average  │
               │   or Meta-Learner)  │
               └──────────┬──────────┘
                          │
                          ▼
               ┌─────────────────────┐
               │  Final Prediction   │
               │  (MW/hour)          │
               └─────────────────────┘
```

#### 3.2.2 모델 상세 스펙

| 모델 | 대상 | 아키텍처 | 입력 시퀀스 | 예측 범위 |
|------|------|----------|-------------|-----------|
| Solar-Net | 태양광 | Bi-LSTM + Attention | 24시간 | 1~48시간 |
| Wind-Net | 풍력 | Temporal Fusion Transformer | 48시간 | 1~72시간 |
| Ensemble | 통합 | Gradient Boosting Meta | 두 모델 출력 | 최종 예측 |

### 3.3 시각화 대시보드 (Frontend)

#### 3.3.1 Map View
- 제주도 지도 위에 발전소 위치 마커 표시
- 실시간 예측 발전량 히트맵 오버레이
- 지역별 발전 효율 색상 구분

#### 3.3.2 Chart View
- 실측값 vs 예측값 시계열 비교 그래프
- 오차율(MAPE) 실시간 표시
- 24시간/48시간/72시간 예측 구간 선택

#### 3.3.3 Alert System
- 출력 제어(Curtailment) 예상 시점 경고
- 급격한 발전량 변동 알림
- 예측 정확도 임계치 이탈 알림

## 5. 성공 지표 (Metrics)

### 5.1 모델 성능 지표

| 지표 | 목표값 | 측정 방법 |
|------|--------|-----------|
| **MAPE** | < 10% | 시간대별 예측/실측 비교 |
| **RMSE** | 베이스라인 -20% | 제곱 오차 평균 제곱근 |
| **R² Score** | > 0.85 | 결정 계수 |

### 5.2 시스템 성능 지표

| 지표 | 목표값 | 비고 |
|------|--------|------|
| API 응답 시간 | < 500ms | P95 기준 |
| 모델 추론 시간 | < 100ms | 단일 예측 기준 |
| 데이터 갱신 주기 | 1시간 | 실시간 파이프라인 |
