# 모델 성능 업데이트 1차: 태양광 최근 120일 학습창 비교 (2026-11-14)

## 결론

JMA MSM day2 예보를 쓰는 island_mean 모델의 2024년 rolling-origin CV에서 기존 누적 학습 대비 최근 120일 학습은 FER을 개선하지 못했다. 풀링 FER은 각각 8.752334%와 8.851929%로, 최근 120일은 0.099594%p 악화됐다. 이 결과로는 학습창 변경을 채택하지 않는다. 운영 모델과 API는 변경하지 않았다.

## 범위와 방법

- `scripts/experiment_solar_rolling120_cv.py`: 동일 모델·입력·6개 폴드·평가 시간에서 학습창만 비교한다. 각 폴드의 학습은 첫 예측일 전날 10:00에 종료된 구간까지 허용하며 최근 120일 조건은 그 시점 기준이다. 예측은 각 폴드 전체에 대해 해당 폴드 시작 전 한 번 적합한 모델로 수행한다.
- 2024-05-01부터 2024-11-07 06:00 직전 시작 구간까지 평가한다. 입력 CSV 로더는 원본 파일을 통째로 읽은 뒤 시험 시작 시각까지 자르므로 파일 자체에 대한 접근과 시험구간을 분석에 사용하는 것은 구별해야 한다. interval-END 2024-11-07 06:00은 시험 시작 전에 시작한 마지막 구간이다.
- 분모는 선택용 대용값 384.87 MW, 평가지표는 실측이 분모의 10% 이상인 시간의 KPX FER이다. 두 후보 모두 평가 대상 1,704시간이며 전체 예측 구간은 4,566시간이다. 아래 풀링 수치는 적격 시간별 오차의 평균이지 월별 FER의 단순 평균이 아니다.
- day2는 과거 예보 가용성의 대용 기준이다. 실제 발행·도착 시각과 발전 실적 공개 지연을 검증하지 못했으므로 엄밀한 운영 실적이 아니다. 관측기상 상한이나 소진된 시험구간의 FER과 직접 비교하지 않는다.

| 폴드 시작 | 누적 학습 FER | 최근 120일 FER |
|---|---:|---:|
| 2024-05-01 | 10.710319% | 10.710319% |
| 2024-06-01 | 9.353858% | 9.668071% |
| 2024-07-01 | 11.066876% | 11.979265% |
| 2024-08-01 | 6.012117% | 5.967120% |
| 2024-09-01 | 7.489953% | 7.250031% |
| 2024-10-01 | 8.085990% | 7.772103% |
| 전체 적격시간 풀링 | 8.752334% | 8.851929% |

5월은 가용 학습기간이 120일보다 짧아 두 조건이 같다. 일부 후반 폴드는 개선됐으나 전체 풀링은 악화됐다. 추가 후보 탐색이나 통계적 유의성 검정은 하지 않았으며, 이 CV 결과만으로 다른 시기 성능을 확정할 수 없다.

## 밴리스트 및 시험구간 사고 기록

풍력 interval-START 재학습, 풍력 편향 보정, MOS 재선택, 특허 2단 재시도 및 2025 hold-out 재평가는 수행하지 않았다. 본 학습창 실험의 평가와 선택에는 2024-11~12 시험구간을 쓰지 않았다.

단, 에이전트와 위임 작업자가 전체 테스트를 실행하는 과정에서 `test_saved_model_reproduces_reported_test_metrics`가 소진된 2024 시험구간의 저장 모델 예측을 다시 계산했다. 사용자 지시를 위반한 실행이다. 그 결과는 위 후보 선택에 사용하지 않았고 시험 성능을 재보고하지 않는다. 후속 테스트에서는 이 테스트를 명시적으로 제외했다. 향후 테스트 실행 전 이 항목을 제외해야 한다.

검증: `.venv/bin/python -m pytest tests/ -q --ignore=tests/test_models.py -k 'not test_saved_model_reproduces_reported_test_metrics'` → 121 passed, 1 deselected. `tests/test_models.py`는 선택적 PyTorch 의존성 때문에 제외했다. 경고 881건은 제거하지 않았다.

## 풍력 데이터 후속 조사

[KPX 지역별 시간별 데이터](https://www.data.go.kr/data/15065269/fileData.do)는 제주 전체 물리적 발전량이 아닌 시장 참여 발전기의 전력거래량으로, 직접거래·자가용 등을 제외한다. [KPX 2025 제주 계통 운영실적](https://kpx.or.kr/boardDownload.es?bid=0159&list_no=76777&seq=2)에 기재된 제주 풍력 연간 발전량은 전년 대비 증가했다는 별도 조사 결과가 있으나, 두 통계의 집계 범위는 서로 같다고 확인되지 않았다. 따라서 공개 라벨의 급감을 제주 전체 발전 붕괴로 해석하거나 원인을 단정할 수 없다.

공식 원인은 아직 미확인이다. [제주 연료원별 시간대별 데이터](https://www.data.go.kr/data/15138838/fileData.do)의 실제 값과 집계 범위를 기존 라벨과 대조하고, KPX에 2025-02-24 전후 집계 대상·연료원 분류·정산 변경 이력을 문의하는 것이 다음 경로다. 이번 라운드에는 추가 파일을 대조하거나 기관에 문의하지 않았다.

## 다음 과제 후보

ECMWF IFS day2의 과거 데이터 확보 가능성이 별도 조사에서 확인됐으나 실제 예보의 마감 전 가용성은 미검증이고 성능 비교도 수행하지 않았다. 출처·라이선스·발행 및 입수 시각을 먼저 검증한 뒤, 기존 JMA와 동일한 기간·대상으로 비교하는 방안을 검토할 수 있다. 시험구간과 기존 hold-out은 모델 선택에 재사용하지 않는다.
