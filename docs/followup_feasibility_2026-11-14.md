## 태양광 학습 주기

기존 2024년 시험 전 rolling-origin CV에서 최근 120일 학습 FER 8.851929%, 누적 학습 8.752334%로 120일 창은 채택하지 않았다. day2는 예보 실제 도착 시각의 대용 기준이며 발전량 공개 지연도 검증되지 않은 연구 결과다. 자세한 조건과 시험구간 재실행 사고는 `round1_rolling_training_window_2026-11-14.md` 참조. 반복 학습 주기 자체가 검증된 것은 아니다. 기존 2025 관측기상 hold-out과 소진된 2024 시험구간을 후보 선택에 재사용하지 않는다. 새로운 평가에는 실제 발행·입수 시각을 확인할 수 있는 과거 예보, 발전량 공개 시각, 아직 선택에 사용하지 않은 후속 기간이 필요하다.

## API 발전 수준 특성

현재 API는 `lvl_p` 또는 정규화 모델을 명시적으로 거부하며 island-mean 기상 피처를 생성한다 (`api/service.py:181-198`). 연구용 `generation_level`은 일별 발전량과 물리 출력 대용값을 14일 창으로 합산하고 D-2까지 사용하며, 최소 4일의 자료가 필요하고 오래된 값을 계속 이월하지 않는다 (`src/features/solar_features_v2.py:370-402`). D-2까지 쓸 수 있다는 것은 실제 공개 시각을 검증하기 전의 가정이다. 발전량 입력 하나만 추가해 stations_level을 재현하거나 현재 API에 근사값을 임의 주입하는 것은 안전하지 않다. 관측소별 기상·발전 이력과 각 값의 가용 시각을 확보하고 마감 시각별 결측 처리를 명세한 다음, 새로운 기간에 사전등록한 비교가 선행돼야 한다. API나 운영 모델은 변경하지 않았다.

## 다른 NWP와 17시 시나리오

[Open-Meteo Single Runs API](https://open-meteo.com/en/docs/single-runs-api)는 ECMWF IFS를 2024-03-14부터 제공하지만 초기 데이터가 IFS Cycle 49R1 hindcasts라고 명시한다. 해당 자료는 사후 재예측이므로 2024년 실제 운영 당시 이용할 수 있었던 예보로 제시할 수 없다. API의 run 시각도 초기화 시각이지 공개 시각이 아니다. JMA previous_day2 역시 실제 공개·도착 시각을 입증하지 못하므로 기존 CV는 엄격한 가용성 검증을 마친 운영 백테스트가 아니다.

ECMWF 실제 과거 운영 예보 또는 KMA LDAPS에 대해 예보 초기화·공개·입수 시각, 제주 관측소 좌표별 변수, 이력 범위와 라이선스를 확인해야 한다. 확인되면 10시 마감 조건의 공통 시간·동일 분모·결측 정책을 정한 시험 전 rolling CV에서 비교한다. 17시 제출은 별도 제도와 마감 시각을 검증해야 하는 별도 시나리오이며 10시 결과 개선으로 취급하지 않는다. 자료 가용성이 검증되기 전 모델 학습이나 성능 비교는 하지 않았다.

추가 후보: [NCAR의 NOAA GFS 0.25도 운영 예보 아카이브](https://data.ucar.edu/dataset/ncep-gfs-0-25-degree-global-forecast-grids-historical-archive)는 2024~2025년을 포함하는 전지구 운영 예보로 기존 JMA와 다른 모델이다. 다만 제주 실제 파일을 내려받아 변수·예보 유효시각·일사 누적 구간을 확인하지 않았고, 당시 공개·도착 시각도 입증하지 못했다. D-1 10:00 KST는 D-1 01:00 UTC이므로 00 UTC 초기화만으로 마감 전 도착을 가정할 수 없다. 3시간 간격 자료를 사용할 경우 시간별 변환 규칙과 interval-END 정합성도 미리 정해야 한다. [NOAA 변수 예시](https://www.nco.ncep.noaa.gov/pmb/products/gfs/gfs.t00z.sfluxgrbf001.grib2.shtml)는 해당 아카이브 파일의 변수 포함을 증명하지 않는다. NCAR 메타데이터의 표기 라이선스는 CC BY 4.0이다.

[기상청 LDAPS 안내](https://data.kma.go.kr/data/rmt/rmtList.do?code=340&pgmNo=65)는 2026년 3월 UM 자료 제공 중단과 대용량 신청 절차를 안내한다. 2024~2025년 별도 제공 가능성, 변수·비용·이용조건·당시 공개 지연은 확인되지 않았다. [ECMWF 운영 아카이브](https://www.ecmwf.int/en/forecasts/datasets/operational-archive)도 이용 가능성과 비용 확인이 필요하다. 어떤 후보도 아직 마감 시각 인증을 통과한 자료로 채택하지 않았다.

## 일사·운량 보정

`mos_nwp_correction.md`에 따르면 기존 2024년 시험 전 rolling CV에서 `linear_cloud`의 FER은 8.579%, 무보정은 8.752%였다. 이는 일사량 보정에 예보 운량을 입력으로 추가한 결과이며 운량 자체를 보정한 검증 결과가 아니다. 0.17%p가량의 차이는 실제 발행·도착 시각과 관측 공개 지연을 검증하지 못한 대용 조건에서 얻은 탐색 결과다. 운량 자체의 보정은 별도로 남아 있고, 기존 관측 기상 값의 마감 전 가용성을 확인하고 미사용 기간을 확보하기 전에는 운영상 개선으로 주장하거나 채택하지 않는다.

## 외부 의존성

풍력은 `wind_2025_coverage_source_check.md`에 기록한 KPX 집계 범위·분류 변경 및 제주에너지공사 값의 일별 집계 정의에 대한 기관 확인이 필요하다. 문의는 발송하지 않았다. 새로운 NWP 자료와 미사용 평가 기간이 확인되기 전 운영 모델 변경이나 유효한 후속 비교가 완료됐다고 주장하지 않는다.
