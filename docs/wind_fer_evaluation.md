## 2. 라벨: interval-END 통일

- KPX 거래시간 h는 (h−1, h] 구간. 공개 파일 `kpx_jeju_generation.csv`는 거래시간 h를
  date+(h−1)로 기록 → **interval-START 라벨** (태양광 문서의 기존 misalignment와 동일 문제).
- 실측 검증(2026-11-10): corr(wind_mw[파일라벨 T], 풍속[T]) = 0.894 <
  corr(wind_mw[파일라벨 T], 풍속[T+1h]) = 0.948 → 파일 라벨이 START임을 확인.
- END 라벨 변환: `wind_mw_END[T] = wind_mw_파일[T − 1h]` (pandas `shift(1)`).
  기상(ASOS 일사는 (t−1, t] 적산, 풍속은 t 순간값)과 정렬된다.
- 마지막 시각(12-31 23:00, 구간 (23:00, 24:00])은 END 슬롯이 2025년이라 제외(1 h).

## 3. 2024-06-01 커버리지 브레이크 처리

- 제주 입찰제도 시행(2024-06-01)부터 공개 풍력 계열은 제주 전체의 18~35%만 담긴다
  (최대 출력 282 → 102 MW). 이것이 기존 풍력 "컨셉 드리프트"의 주원인.
- **처리: 브레이크 후 데이터만 학습·평가** (2024-06-01 01:00 ~ 11-06 학습, 11-07~12-31 테스트).
  브레이크 전 데이터는 분모·포괄률 추정에만 사용한다. 브레이크 전 계열은 스케일이 달라
  혼합 학습이 불가능하고, 사후 스케일링보다 단순·검증 가능하다.
- 부수 관찰: 브레이크 후 월별 최대가 6월 45.6 → 12월 101.8 MW로 계속 상승 →
  포괄 설비가 연내 계속 확대됨. 테스트 윈도우(11~12월)의 실효 용량이 연평균 포괄률보다
  크다는 뜻이며, 이는 민감도 상단(106.7 MW)과 plateau 교차검증(§4)에 반영됨.

## 4. 실효 용량 분모 산정 (태양광 문서 §3 방법의 풍력 적용)

저장소에 제주 풍력의 공식 시장참여 용량 등록값은 없다(KPX 제주본부 운영실적 미보유) →
데이터 기반 산정 + 민감도 보고 (태양광 C=359.4 MW, 민감도 342.3~449.5 MW와 동일 구조).

1. **앵커 C_pre = 282.13 MW** = 2024-01-01~05-31 관측 최대. 이 시기는 공개 계열이
   시장 전체와 일치함이 태양광에서 확인됨(월별 포괄률 1.00~1.015, `solar_evaluation_criteria.md` §3).
   풍력도 동일 시기 전체 포괄으로 가정. 관측 최대이므로 진위 용량의 하한.
2. **포괄률 r** = 브레이크 후 / 브레이크 전 통계 비율:
   - p99: 0.3719 (주값 — 용량에 제한되는 상위 구간이라 계절 편향 최소)
   - 발전량 가중(평균): 0.3290 — 1~5월(강풍기) vs 6~12월 계절 편향으로 과소 추정 경향
   - p99.5: 0.3782
3. **주 분모 C_main = 282.13 × 0.3719 = 104.9 MW**
   민감도: **C_min = 92.8 MW** (×0.3290) ~ **C_max = 106.7 MW** (×0.3782)
4. 교차검증: 테스트 윈도우(11~12월, END 라벨) 실측 최대 101.83 MW, p99.9 = 99.9 MW →
   계열 plateau 약 102~105 MW로 C_main=104.9 MW와 일관.

FER = |예측 − 실측| / C × 100, 평가 대상은 실측 ≥ 10% × C 시간
(전력시장운영규칙 제14.1.1조 별표2 Ⅴ). 정산 티어 2021(≤6% 4원, 6~8% 3원)에 제주
2024 ×0.5 (jfpf=0.5) 적용.

## 5. 모델 선택 (테스트 윈도우 무사용)

- 월별 rolling-origin CV: 검증월 8/9/10월, 학습은 검증월 직전까지(브레이크 후만).
- 후보 4개: LightGBM 기본값 / Phase-5 파라미터 / Phase-5+시간가중 0.999 / +0.9995.
  Early stopping은 각 fold 학습 구간 말단 20%(시간순)로 수행.

## 6. 테스트 윈도우 규칙

2024-11-07~12-31은 태양광에서 이미 2회 사용됐다(태양광 문서 §6·§7). 풍력에서도
재사용 금지 원칙을 동일 적용: 모델 선택·튜닝은 전부 CV로 수행했고, 테스트는
사전 등록된 `phase5_tw0999` 설정으로 **딱 한 번** 실행했다(위 표가 그 기록).
스크립트 재실행 시 동일 파이프라인이 재현된다(재튜닝 후 재실행은 금지).

## 7. 한계

- 관측 기상 입력 = 성능 상한. D-1 전일 조건(풍력 NWP)에서는 더 나쁠 것.
- 분모는 관측 최대 기반 추정이라 진위 용량의 불확실성 포함(민감도로 보고).
- 9월 CV FER 14.3%가 월별 변동의 주범 — 태풍·전환기 저풍속 구간의 예측 난이도.
- 2024-06-01 이후 포괄 설비가 계속 확대 중 → 이후 연도 데이터로는 분모를 재산정해야 함.
- 2025 KPX 데이터(스키마 드리프트 있음)는 별도 fresh hold-out으로만 사용 가능.
